### ✨ About the Project

A beautiful **3D Folding Card Animation** created with **Pure CSS** only.  
Hover over the card to unfold it with a smooth and realistic 3D effect.

> ✅ No JavaScript  
> ✅ No Libraries  
> ✅ Lightweight & Smooth  

Perfect for portfolios, landing pages, interactive sections, and modern UI designs.

---

### 🎯 Features

- 🃏 Realistic 3D folding animation
- ⚡ Smooth hover transition
- 📱 Fully responsive
- 🎨 Modern dark theme design
- 💻 Pure CSS (No JavaScript)
- ♿ Accessible (keyboard focus support)

2. Open `index.html` in your browser
